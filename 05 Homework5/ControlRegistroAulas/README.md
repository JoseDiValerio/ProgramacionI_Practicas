**PROYECTO DE APLICACIÓN DE CONTROL DE RESERVAS DE AULAS** 



**Descripción:** 



Aplicación sencilla que permite registrar aulas, profesores y reservas para organizar el uso de las aulas de una institución. 



**REQUERIMIENTOS FUNCIONALES** 



**Registro de Aulas** 



La aplicación debe permitir ingresar: 



• Código del aula. 

• Nombre del aula. 

• Capacidad del aula. 



**Mostrar Aulas** 



La aplicación debe mostrar los datos de las aulas registradas. 



**Registro de Profesores** 



La aplicación debe permitir ingresar: 



• Código del profesor. 

• Nombre del profesor. 

• Materia que imparte. 



**Mostrar Profesores** 



La aplicación debe mostrar los datos de los profesores registrados. 



**Registro de Reservas** 



La aplicación debe permitir ingresar: 



• Aula. 

• Profesor. 

• Fecha. 

• Hora de inicio. 

• Hora de finalización. 



**Mostrar Reservas** 



La aplicación debe mostrar las reservas realizadas con los datos del aula, profesor, fecha y horario. 



**Validación de Datos** 



La aplicación debe verificar que: 



• Los datos obligatorios no estén vacíos. 

• Los códigos sean números válidos. 

• La capacidad del aula sea un número mayor que cero. 

• La hora de finalización sea mayor que la hora de inicio. 

• El aula seleccionada exista. 

• El profesor seleccionado exista. 

• El aula no esté reservada para la misma fecha y horario. 



**Modificar Datos**



La aplicación debe permitir modificar los datos de un aula, profesor o reserva. 



**Eliminar Datos** 



La aplicación debe permitir eliminar un aula, profesor o reserva registrada. 



**Menú Principal** 



La aplicación debe mostrar un menú con opciones para: 



1\. Gestionar Aulas 

2\. Gestionar Profesores 

3\. Gestionar Reservas 

4\. Salir. 



**Menú Gestionar Aulas**



La aplicación debe mostrar un menú con opciones para: 



1\. Registrar Aula 

2\. Editar Aula 

3\. Listar Aulas 

4\. Eliminar Aulas 

5\. Regresar 



**Menú Gestionar Profesores** 



La aplicación debe mostrar un menú con opciones para: 



1\. Registrar Profesor 

2\. Editar Profesor 

3\. Listar Profesores 

4\. Eliminar Profesores 

5\. Regresar 



**Menú Gestionar Reservas** 



La aplicación debe mostrar un menú con opciones para: 



1\. Guardar Reservación 

2\. Editar Reservación 

3\. Listar Reservaciones 

4\. Eliminar Reservaciones 

5\. Regresar





**REQUERIMIENTOS NO FUNCIONALES** 



**Facilidad de Uso** 



La aplicación debe tener un menú sencillo y fácil de entender. 



**Mensajes** 

La aplicación debe mostrar mensajes claros cuando una operación sea correcta o cuando exista algún error. 



**Tiempo de Respuesta** 



La aplicación debe mostrar los resultados inmediatamente después de realizar una operación. 



**Simplicidad** 



La aplicación debe utilizar conceptos básicos de Programación 1, como variables, condicionales, ciclos, listas y clases sencillas.
